# Security

| Threat | Control |
|---|---|
| Silent overwrite | Append-only parent-linked versions |
| Context mixing | Separate active head per normalized scope |
| Leader decides compatibility | Validators independently recompute every field |
| Tolerance admits conflicting state | Fixed enums and exact equality |
| Unverified prose affects later updates | No reasoning or summary is stored |
| Ambiguous memory auto-activates | Unknown/ambiguous vectors require review |
| Sensitive constraint weakening | High/critical changes require owner resolution |
